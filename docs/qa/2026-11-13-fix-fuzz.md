# Android fix-and-fuzz, 13 November 2026

Baseline: `84178d7e7654f25e99f15854b19da7a71e3980de` (main).

## Fixed and regression-tested

- UTF-8 fallbacks: unpaired UTF-16 surrogate consumed an adjacent character;
  malformed/truncated UTF-8 decoded to incorrect characters. Both entrypoints
  now import one tested fallback before dependent modules. Existing native
  implementations are preserved; UTF-8 streaming, BOM, fatal, buffer views,
  and encodeInto have differential coverage.
- Quantity parsing: inherited object properties such as `constructor` were
  accepted as units; conversion could overflow; epsilon rounding could turn a
  tiny positive requirement into zero packages and zero cost.
- Item editing: remote sync could overwrite an unsaved draft, then a save could
  overwrite untouched remote fields. Save now sends only dirty fields. Missing,
  deleted, or wrong-list targets cannot silently become newly created items.
- Synchronous submit gates prevent same-frame duplicate list/item submissions.
  Pending list modal cannot be reopened; late async completion does not pop an
  unrelated screen. Quantity stepping is finite and bounded.
- Standalone offline `.qa` Android variant, separate storage/identity, removes
  INTERNET/BILLING and production deep links. APK guard script verifies these.

## Boundaries and unresolved checks

- No production deployment, purchase, shared list mutation, or live enrollment.
- npm audit of the production dependency tree reported 43 advisories (5 low,
  16 moderate, 21 high, 1 critical), including build tooling in that dependency
  tree. This is not 43 demonstrated app exploits. SDK/crypto dependency upgrades
  require separate compatibility/reachability review; no blind audit fix.
- Real sync, pricing, purchases, image upload, telemetry and enrollment are
  intentionally unavailable in the offline QA variant and are not certified.
